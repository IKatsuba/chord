# CHD-523: one line per agent, with no session title

The owner (2026-10-25, CHD-523 and its comment): the agents list under the
prompt shows no session title in any row. This includes main, children,
a team's lead and every nested member when unfolded. The agent's name is
enough. Each agent takes one line. This supersedes only CHD-445's agents
list design; `/resume` keeps its titles.

## Rows at 80×24

Before, main's title fills the visible list; its continuation and the
other agents need scrolling:

```text
    main       Запуск разработки          fake  ◦ idle 51s
               майлстоуна 0.60 —
  ↓            проверка длинного
    … +3 more
```

After, each visible agent has one row. Existing list limits, scrolling,
model/detail fitting and team folding decide which rows fit. For example,
with a team member picked (schematic rows):

```text
    bugfix     team · fake  ◦ idle 7s
    ├─ tester  fake         ✻ working 7s
  ❯ └─ coder   fake         ◦ idle 7s
    … +3 more
```

A long session title adds no lines in any state: empty/idle, streaming,
waiting for permission or input, failed/exited, or narrow. No new empty,
loading or error treatment is introduced. A session without a title has
the same row shape as one with a title.

## What stays

Agent names, tree glyphs, runtime/model/mode details, states and elapsed
times, unread marks, picked row, folded-team summary, list height and
navigation keep their existing rules. A title update changes no list row.
Titles remain in `/resume`, the start picker, resumed headers and terminal
status as before. Task titles and transcript tool-call titles also stay.

Colour roles remain those of `src/ui/theme/theme.ts`: `agents` for child
names; terminal text for main; `accent` with dim for work (the existing
16-colour green choice); dim idle and unread news; `warning` for waits and
`error` for failures. The picked agent's prompt border keeps its colour.
No new role, glyph or colour is needed.

No action or key is added. From the empty prompt, ↓ enters the list;
↑/↓ or j/k pick, Enter writes to the picked agent, Esc returns, and x
closes with the existing busy confirmation. `ctrl+x a` reaches what waits.
The shortcuts panel stays as it is.

## Evidence

`evidence/CHD-523/` holds whole-window colour PNGs and plain-text captures
at 120×40 and 80×24. `before-*` is origin/main `a3d59601`; `after-*` is U1.
`folded` shows main and children; automatic folding hides the team
members where the list needs it (at 120×40, U1 fits all six rows). `team` picks the
lead; `members` picks a nested member. Before, wrapped titles can hide the
other rows even with the team unfolded.

The existing fake agent supplies the scene: `CHORD_FAKE_TITLE` sets a long
non-ASCII title at session creation; `agentstitled` opens parser and docs
and gives them distinct titles; `team` runs the existing fake `bugfix`
team with tester and coder, with tester on `costwait`. No real agent or
model is contacted. PNGs are rendered from `tmux capture-pane -e -p`
using a task-local copy of the existing CHD-483 ANSI renderer.

Passed on `69c1555fb26854021bb8676b55b037b29c107e29`: main, parser,
docs, bugfix, tester and coder each occupy one row at 120×40. At 80×24,
main and children fit beside the folded team; picking coder shows the

light-theme, live-agent, compile or whole-suite check was made for this

error or permission scenario was run. All designer tmux sessions were
killed and the baseline worktree was removed.
