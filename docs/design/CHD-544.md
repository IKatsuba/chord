# CHD-544: the startup picker lists only agents chord can start

The owner, 2026-10-28: when chord starts with no agent named, the picker
shows only runtimes chord can actually start, in the sense `chord agents`
uses. A row whose own CLI is not on PATH (`found === false`) is dropped.
npx and uvx entries stay, and so do the names the settings files define,
whether they give a command for a registry agent or a name of their own.

Out: `/new`'s command list, which keeps `· not on PATH` in its notes, and
what happens when a missing agent is named on the command line.

## The screen

Nothing new is drawn. The picker is today's `Select agent` list
(`AgentPicker`), less the rows that cannot start. Because no row is left
that is missing, the dim ` · not found` suffix has nothing to say and goes:
a row is the name, then ` · <title>` dim where the title differs from it,
as today.

Rows keep their order (registry, then the table's own CLIs, then the
settings-only names) and are numbered by where they stand on the list, so
the numbers close up: on this machine `fx` moves from 28 to 27, and the
list ends there instead of at 36.

The header line (`chord` and the directory), the blank space above the
list, the scroll gutter and the hint line are unchanged.

## States

- **Opening.** The highlight opens on the preferred agent (settings
  `agent`, else the default), as today.
- **Preferred agent hidden.** When the preferred agent is an own CLI not on
  PATH, its row is not on the list, and the highlight opens on row 1 with
  the list at its top. Nothing says why: the person picks what can start.
  The settings stay as they are.
- **Empty.** If nothing is left, the existing `No agents available` (dim)
  and the hint line with only `Esc to cancel` stay as they are. With the
  registry's npx entries always listed this is not expected in practice.
- **Narrow.** At 80×24 the list shows fewer rows, as today; no label
  changes width except that the ` · not found` suffix is gone.

## Colour roles

Unchanged: the label in the ordinary text colour, the title dim (SGR 2),
the highlighted row and its `❯` in `permission`, the gutter and
`… +N more` dim.

## Keys

Unchanged: ↑/↓ or k/j move, Enter or 1–9 pick, Esc or ctrl+c cancel. The
shortcuts panel needs no new entry.

## Why

A row that cannot start is a choice that fails after it is made. Dropping it
is quieter than marking it, and `chord agents` stays the place that says
which own CLIs are missing. Opening on row 1 when the preferred agent is
hidden keeps the picker's one rule, a highlight on a row that is there,
without inventing a notice the task does not ask for.
