
Usage:   chord [agent]
Version: 0.0.0

Description:

  A full-screen terminal client for ACP coding agents.

Options:

  -h, --help                                 - Show this help.
  -V, --version                              - Show the version number for this
                                               program.
  -C, --cwd                       <dir>      - Directory the session works in.    (Default:
                                                                                  "/private/var/folders/j6/1vnjt67d3h54
                                                                                  1g_33c_70w5c0000gn/T/tmp.jWtFkLICSp/p
                                                                                  roj")
  --agent-command                 <command>  - Start this ACP agent command
                                               instead of the registry's;
                                               [agent] only names it.
  -m, --model                     <model>    - Start each of [agent]'s sessions   (Conflicts: --print)
                                               on this model, by its id for it.
  --permission-mode               <mode>     - Start each of [agent]'s sessions
                                               in this mode, by its id for it.
  -c, --continue                             - Open the agent's latest session    (Conflicts: --resume)
                                               in this directory again.
  -r, --resume                    <id>       - Open a session by the id chord
                                               prints on quit; repeated, a tab
                                               each.
  -p, --print                     <prompt>   - Send this prompt, print the reply  (Conflicts: --continue, --resume)
                                               and exit; piped input joins it.
  --dangerously-skip-permissions             - Allow every permission the agent
                                               asks for. Only with -p.
  --output-format                 <format>   - How -p prints: the reply as it     (Depends: --print, Values: "text",
                                               streams, or one JSON object at     "json")
                                               the end.

Commands:

  agents  - List the agents chord can start: name, title and command.

Examples:

  Claude Code                  chord claude
  Pick up where you left off   chord claude --continue
  Codex in another directory   chord codex -C ~/src/app
  One question, for a script   chord -p "What does this do?"
  Piped input with the prompt  git diff | chord -p "Review this" --output-format json
  An agent chord does not know chord my-agent --agent-command "my-agent --acp"

  error: Session aaa is named twice.

exit 2
