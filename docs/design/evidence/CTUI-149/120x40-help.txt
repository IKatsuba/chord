Usage: chord [agent]
Version: 0.0.1

A full-screen terminal client for ACP coding agents. A new unnamed interactive start asks which agent to use for this in
vocation; explicit commands, headless and resume routes keep their existing behavior.

Options:
  -h, --help                            Show this help.
  -V, --version                         Show the version number for this program.
  -C, --cwd=<dir>                       Directory the session works in.
      --agent-command=<command>         Start this ACP agent command instead of chord's own; [agent] only names it.
  -m, --model=<model>                   Start each of [agent]'s sessions on this model, by its id for it.
      --effort=<effort>                 Start each of [agent]'s sessions on this effort, by its id for it.
      --permission-mode=<mode>          Start each of [agent]'s sessions in this mode, by its id for it.
      --no-mcp-servers                  Start each of [agent]'s sessions with no MCP servers, chord's own included.
  -c, --continue                        Open the agent's latest session in this directory again.
  -r, --resume [id]                     Open a session by the id chord prints on quit; with no id, pick one.
  -p, --print=<prompt>                  Send this prompt, print the reply and exit; piped input joins it.
      --dangerously-skip-permissions    Allow every permission the agent asks for. Only with -p.
      --output-format=<format>          How -p prints: the reply as it streams, or one JSON object at the end.

Commands:
  agents   List the agents chord can start: name, title, command, and for those started by their own CLI whether PATH ha
s it.
  acp      Serve ACP on stdin and stdout, for a client that starts chord as its agent; draws nothing.
  upgrade  Upgrade chord executable to latest or given version.

Examples:
  Claude Code                   chord claude
  Pick up where you left off    chord claude --continue
  Pick an earlier session       chord --resume
  Codex in another directory    chord codex -C ~/src/app
  One question, for a script    chord -p "What does this do?"
  Piped input with the prompt   git diff | chord -p "Review this" --output-format json
  An agent chord does not know  chord my-agent --agent-command "my-agent --acp"
