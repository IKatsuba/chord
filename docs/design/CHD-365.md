# CHD-365: a turn the agent started on its own, cancelled

CHD-364 has the shape for steered and held messages. This file covers one more
sequence, from the owner's option C. Codex answers a steer that missed the turn
with `startedNewTurn`, chord cancels that turn at once, and the message goes as
chord's next turn.

## What reads wrong today

The cancelled turn has no turn of chord's, so its updates fold under the last
turn. Its first chunk continues that turn's last reply:

```
 → @main
   ⎿  All 214 parser tests pass now.

 ⏺ I will run the parser tests on each change.Received the message from main.

 ← @main
   ⎿  I changed how a string at the end of a line is read. Run the parser tests now and tell me only what fails.

 ⏺ Received the message from main.
```

Two things read badly:

- The two replies run into one sentence, and the earlier turn's answer now ends
  with words it never said.
- The agent says it got a message the screen has not shown yet. The message only
  draws below, and then the agent answers it a second time. Nothing says why it
  spoke out of turn or why it answers twice.

## The shape

What the cancelled turn sent is drawn as a block of its own, never run on to an
earlier reply. It is closed by one outcome line under it, like a turn the person
interrupted. The message then goes as chord's next turn, as it does now.

```
 → @main
   ⎿  All 214 parser tests pass now.

 ⏺ I will run the parser tests on each change.

 ⏺ Received the message from main.
   ⎿  Interrupted · the agent started this on its own; @main's message goes as the next turn

 ← @main
   ⎿  I changed how a string at the end of a line is read. Run the parser tests now and tell me only what fails.

 ⏺ Received the message from main.
```

At 80 columns the outcome line cuts at its end, like every `⎿` line. The part
that matters comes first:

```
⏺ Received the message from main.
  ⎿  Interrupted · the agent started this on its own; @main's message goes as…
```

### The rules

- **Its own block.** An update chord did not ask for, coming after a
  `startedNewTurn`, never continues a block from a turn of chord's. A message
  chunk starts a new `⏺`, and a tool call is drawn as its own `⏺` as usual.
- **One outcome line**, drawn when chord sends the cancel. It sits under what
  the turn has drawn so far, and anything that arrives after the cancel draws
  above it. It takes the dim tone of a stopped turn, not the red of an
  interrupted one: nothing went wrong for the person, and they did not press
  Esc. The words say it was the agent's turn, not theirs, and where the message
  went.
- **The line is drawn even when the turn sent nothing** before the cancel
  landed. That is the usual case live: the engineer's check against codex-acp
  2.1.1 saw the cancel land before Codex said anything. Then the line stands
  alone, as a `⏺` of its own:

  ```
   ⏺ Interrupted · the agent started this on its own; @main's message goes as the next turn

   ← @main
     ⎿  I changed how a string at the end of a line is read. …
  ```

  Without it, a tool the agent ran in that moment, and then cancelled, would sit
  in the transcript with nothing saying why it stopped. _Alternative, if the
  owner holds to "nothing extra": draw no line when the turn sent nothing, and
  the line only when it did. The rule about a block of its own still holds._
- **Nothing else changes.** No spinner for the cancelled turn, no queue row
  while the cancel lands, and the sender's `→` row as it is (decisions.md
  already records that it says "went in").
- **Replay.** A resumed session draws the block and its line in the same place,
  so the record keeps the cancel as it keeps any outcome.

### Keys

None. Chord cancels the turn itself; the person does nothing.

### Why

The owner accepted that the agent may half-act on the message before the cancel
lands. If half-acting is acceptable, the screen has to show it, and show it as
stopped. Hiding the turn's updates would hide a tool call that ran. Folding them
into the previous reply makes them look like that reply's words. A block of its
own with an outcome line reads like what happened: the agent began, chord
stopped it, and the message went the normal way.
