# Code of conduct

chord follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep criticism to the work, not the
person. Harassment of any kind is not tolerated, in issues, pull requests,
discussions or anywhere else the project is.

To report behaviour that breaks it, open a private
[security advisory](https://github.com/IKatsuba/chord/security/advisories/new)
titled "Conduct", which only the maintainer sees. Reports are kept
confidential, and the maintainer decides what follows, from a word in private
to a ban from the project.
