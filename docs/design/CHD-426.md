# CHD-426: an agent's own cycle

An agent may work again after its turn has ended with nobody prompting it:
Claude Code when a background task ends (origin `task-notification`),
codebuddy's unasked turn. The owner (2026-10-19) settled what chord does:

- **Q49:** chord recognises a cycle only where the wire marks its end:
  Claude's autonomous `usage_update`, and codebuddy's
  `codebuddy.ai/unsolicitedTurn` start and `session_end`. A cycle starts on
  the first agent update after a turn has ended and gone quiet (or on
  codebuddy's marker) and ends on the marker. Other agents stay as before.
- **Q47:** a prompt the person sends during a cycle goes at once; on Claude
  it takes the cycle over, and its turn replaces the cycle on screen.
- **Q48:** a permission or form asked inside a cycle is held as CHD-158
  holds a request between turns: drawn without the keys, `ctrl+x a` to
  answer.

## The rule: a cycle looks like a turn

**Nothing new on screen and no new words.** While a cycle runs, every place
that shows a turn shows it the same way, because to the person it is the
agent at work, whoever started it:

| Where | During a cycle |
| --- | --- |
| Under the transcript | `››› Working… (2s · esc to interrupt)`, counted from the cycle's first update |
| The tab bar | the working glyph, `1 fake ✻` |
| The agents list | `✻ working 3s` on the agent's row |
| `esc` | ends it: `⎿  Interrupted by user` under its last block, as a turn's Esc |
| Its end | the transcript as it stands, and the turn-end notification (BEL in tmux) |
| A prompt sent | goes at once (Q47): `› …` and its reply; the working line is the new turn's |
| A permission or form | held as CHD-158 §3 draws it: `main asks · between turns`, `ctrl+x a to answer`, status `● permission · ctrl+x a to answer` |

**Why no word of its own** (such as `· on its own`): the person's question
while it runs is the same as in a turn, whether the agent is busy and how
to stop it, and the line already answers both. What started the cycle is
written above it in the agent's own words (`The background build ended;
reading its log.`). A second kind of working line would be one more thing
to read for no different action.

**Why a held request says `between turns`:** the person did not prompt this
work and may be typing, so the box takes no keys (Q48). From the person's
side it is between their turns, and the words match CHD-158's.

## Colour roles and keys

No new role: the working line, glyph and list state keep a turn's. No new
key: `esc` interrupts as in a turn, `ctrl+x a` answers a held request as
CHD-158 says, and the shortcuts panel's lines stand.
