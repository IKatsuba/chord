 ⏺ Reading the session layer

   The session layer wraps acpx so the interface never touches a process. Start
   with src/session/session.ts, then see the ACP spec
   (https://agentclientprotocol.com) for the wire format.

   What it does

   - opens one persistent session per chord session
   - starts turns with startTurn and cancels them
     1. a cancel stops the turn at once
     2. the agent is told with session/cancel

   That is the whole loop. To land a change:

   1. Run the checks:
     ┌ sh ─────────────┐
     │ deno task check │
     └─────────────────┘
   2. Commit on main once every check has passed and the tree is clean, so
     whoever picks the work up next starts from a build that runs.

   Then build the binary with:

   ┌ sh ─────────────────────────────────────────────────┐
   │ deno task compile --all                             │
   │ for bin in dist/*/chord; do echo "built $bin"; done │
   └─────────────────────────────────────────────────────┘
