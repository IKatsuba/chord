# CHD-336 QA

Implementation: `028ff1f9`; tested main `ef487ea1` on 2026-10-12.
The designer already approved the appearance; this checks behaviour.

## What ran

- Read the current binding CLAUDE.md, README, feature map, relevant decisions
  and the board's chord-tui skill. Current commands use Bun/OpenTUI/ACP SDK.
- Ran `bun run compile` for the host darwin-arm64 binary.
- Started source with `bun run chord:fake -C <scratch>` and the host binary
  with `fake -C <scratch> --agent-command "bun <scratch-repo>/tests/fixtures/fake_agent/main.ts"`.
  Both ran in the foreground of panes in a dedicated tmux socket, with
  isolated XDG configuration/state and neutral working directories under `/tmp`.
- Unset inherited `NO_COLOR`, set `FORCE_COLOR=2` then `3`, and used a dark
  theme. Captured settled headers with `capture-pane -p` and `-p -e` at
  120x40, then resized the same pane to 80x24: eight captures in total.
- Compared level 3 with pre-fix source `09f52c0a`, exported into scratch
  storage with installed dependencies linked, at both sizes.
- At level 2 on source and binary, sent `error`, `slow`, Esc and `text` by
  separate literal-text and Enter calls. Captured failure, interruption
  and the next successful reply at 80x24.
- Quit every run with Ctrl+D; compared exact `stty -g`, read tmux alternate
  screen/cursor flags, and inspected terminal output for cursor, alternate
  screen, mouse and bracketed-paste resets. Checked owned processes with `ps`.
- Ran the full repository check, including the session layer on fake ACP
  agents, with process/loopback access for cleanup assertions.

## What was observed

Host compilation passed and the binary started, drew and accepted keys.

Every level-2 header uses palette indices 121, 85, 78 and 43, including
foreground and background half-cell colours. None has the magenta fallback
`255;0;255`. At both sizes, the mark reads:

```text
 ▀▄     chord v0.0.0
 ▀▀▀▄   fake · Fake Large with a 1M context window
 ▄█▀▀   /tmp/...
 ▀▀     ? for shortcuts · /help
```

Level 3 retains the reported truecolor gradient, including
`48;2;87;234;168`, and its third mark row is `▄▀▀▀`. Source and binary
header ANSI captures match after accounting for their scratch directories,
at each level and size. Pre-fix and current level-3 full-screen ANSI
captures also match at both sizes, normalizing only scratch directories.
Resizing leaves the header and prompt usable.
No run wrote `Invalid hex color` to stderr. Source stderr contains only
Bun's script invocation; the binary's empty-header runs have empty stderr.
The first source probe inherited `NO_COLOR=1`; its uncoloured capture was
discarded and replaced with the explicit colour environment above.
The binary's first 120x40 snapshot was taken before its header settled;
it was also replaced with a readiness-checked capture.

Both source and binary show `The fake agent failed on purpose.`.
Esc during `slow` shows `Interrupted by user`, then `text` replies
`Hello, world. This reply came in chunks.`. The error and interrupt
captures retain the coloured header.

All five accepted runs quit with exit code 0, exact pre/post `stty -g`
match, `alternate=0` and `cursor=1`. Terminal output disables mouse modes
1000/1002/1003/1006 and bracketed paste, leaves the alternate screen and
shows the cursor. Each owned tmux session was removed after that proof.
Final `ps` inspection found no owned source client, host binary or fake
agent process.

Full `bun run check` passed: types, lint and format green; 51 lint tests
and 1,507 repository tests across 113 files, zero failures (495.62 seconds
for the main suite). The staged evidence was included in the privacy gate.

Library first: the change uses installed OpenTUI 0.6.0's `RGBA.fromIndex`
directly. These source/binary captures exercise it through the shared
colour adapter; QA added no component, parser, protocol helper or dependency.
No live agent, push, publish or PR. No new finding or task was needed.
