  01  WHAT IT IS
  ──────────────────────────────────────────────────

  Widgets, state, layout in cells, rich text and
  keyboard actions, with a headless tester. Written
  from scratch, with no dependency on another
  terminal UI framework.

  If you know Flutter you know the names:
  StatelessWidget, StatefulWidget, setState, Row,
  Column, Expanded, Theme.of. It runs on macOS,
  Linux and in browsers. This page is a chord_tui
  app, compiled to WebAssembly.

  README's example, running: a tool call's output
