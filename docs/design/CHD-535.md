# CHD-535: Tab sends the oldest queued message into the running turn

The owner's answers (Q281–Q283, 2026-10-28): Enter sends the draft, or
queues it while a turn runs, as today. Tab sends the **oldest queued
message** into the running turn; press again for the next. Tab no longer
steers the draft. A message refused, or on an agent without steering,
goes back to the top of the queue with a 3 s status note.

## The interaction

Enter during a turn queues, as today (80×24, the region above the box):

```
 ››› Working… (6s · esc to interrupt)
 › Use the second parser instead
 › Then update the changelog
╭──────────────────────────────────────────────────────────────────────────────╮
│ › and keep the old one behind a flag                                         │
╰──────────────────────────────────────────────────────────────────────────────╯
```

Tab sends `Use the second parser instead`, the oldest of the person's own
queued rows, into the turn. The draft stays in the box exactly as it was,
empty or not. Accepted at once, the row leaves the queue in the same frame
its `›` row is drawn in the transcript, and the working line goes on:

```
 ⏺ Read(src/parser.ts)
   ⎿  Read 120 lines

 › Use the second parser instead

 ››› Working… (7s · esc to interrupt)
 › Then update the changelog
╭──────────────────────────────────────────────────────────────────────────────╮
│ › and keep the old one behind a flag                                         │
╰──────────────────────────────────────────────────────────────────────────────╯
```

Tab again sends `Then update the changelog` the same way.

- **Which row.** The oldest of the person's plain queued rows. Not another
  agent's `←` message (not the person's), not a row already
  `into the running turn:` or held `after …:` (already on its way).
- **Order.** Oldest first keeps the order the person typed: what goes in
  now was always going to be read first.
- **Nothing to send.** No turn running, or no plain row of the person's in
  the queue: Tab does nothing and shows no note. The `/` or `@` list, a
  permission, form or question, and bash mode keep their own Tab, as today.
- **Attachments.** The queue entry already holds its images and `@path`
  links; they go with it, and its rows read as the queue reads them today
  (`[Image #1]`, `@README.md`).

## Q4: never lost, never twice

The message is one queue entry whose state changes in place; it is never
copied. Its states, and what the screen shows:

| State | Screen |
| --- | --- |
| Waiting | Plain dim `› text` row, as today. |
| Sent, unanswered 500 ms | `› into the running turn: text`. Esc leaves it (CHD-378 §3). |
| Held | `› after the running calls: text` or `› after your answer: text` (CHD-378 §4). |
| Accepted | Leaves the queue in the frame its `›` row is drawn in the transcript. |
| Refused | Back to the **top** of the queue as a plain row, and the status note below. |
| Agent without steering | Never leaves the queue; the status note below. |
| Turn ends while it is out | The turn's end does not send it. The late answer decides once: accepted → drawn; refused or late → it goes as the next turn, ahead of the other queued rows. Codex `startedNewTurn` as CHD-378 §5. |

### The status notes

Left side of the status line, `warning` tone (the `failed` tone of
CHD-378 §2), 3 s from the last press or refusal, a new one restarting it:

```
  This agent does not take messages into a running turn · it stays queued
```

72 cells; fits 80×24 whole, the model on the right gives way. The same
note when the agent has not said whether it steers (no
`_meta.steering.supported`).

```
  Not taken into the running turn · it stays queued
```

49 cells; for a refusal (`promptRequired` or an error). A late answer after
the turn's end gets no note: the message goes as the next turn, which the
transcript shows.

## Why

Enter is the one way a message is written down; Tab is a decision about a
message already on screen, so the person can see exactly what will go in
before pressing it. The oldest goes first so pushing a message in never
reorders what the agent reads. A refusal now says so, as the task asks;
the row returning to the top keeps it first in line, where it was.
