# Relative-time package trial

[timeago 3.7.1](https://pub.dev/packages/timeago) was inspected and tried
under dart compile exe. Its default English formatter differs from the
original's thresholds and labels; result.txt is observed binary output.
Its locale callback model does not replace unit selection/rounding or add
the original week unit. No adapter around the package was built.

[intl](https://pub.dev/packages/intl) was inspected at 0.20.3: its public
API has date/number/message formatting, no RelativeTimeFormat equivalent.
It resolves in the trial as timeago's dependency. intl4x 1.0.1 was already
tried in CTUI-23; its native ICU4X build hooks fail dart compile exe, as
recorded in that task's collation-trials evidence and decisions entry.
No additional intl4x compilation was run here.

Main approved a narrow English port of the original lastUsed: six fixed
units, flooring and numeric:auto labels, without a timeago workaround.
The checked-in oracle.json was generated by Bun importing the original
lastUsed at original commit 577b58167672e12c999aeaf4eed2a1a988513dc2.
The retained oracle script accepts the original checkout as its argument;
reproduce from a temporary directory with bun oracle.mjs ../chord (resolve
the checkout argument from the repository first). No original source changed.
The package probe and lock are retained as text; compile probe.dart after
pub get using that resolution. Download/resolution required network access;
an initial restricted attempt failed with a socket error before the
successful resolution/compilation. This is package/oracle evidence, not an
implemented port formatter or screen parity result.
