# CHD-534: preserve a failed fx turn truthfully

This slice adds fake-agent regression coverage for the existing display. It
introduces no production UI change. Keep completed tool calls, the agent's
explanation and one terminal error for each failed turn. A later request can
still be submitted. Three separate failed turns remain three separate failures.
