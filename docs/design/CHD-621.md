# CHD-621 — Drop riff, chord's built-in agent

A removal: the screen gets no new look, it loses riff's parts. Every frame
below is one chord already draws, minus riff. The owner's answers of
2026-11-12 (CHD-621's comments) frame it: no migration and no notice for a
person who used riff; riff's keychain entries and stored sessions are left
on disk untouched; `_meta["chord/permission"]`, the permission dialog's
review and deadline, `ui/transcript/tools/paths.ts` and proposed diffs in
permission requests stay.

Captures of each unit against origin/main are in `evidence/CHD-621/`.

## What a person sees afterwards

### The startup picker

riff's first row goes; the list starts at the first catalog agent in name
order and the numbers shift up by one. Nothing else in the picker changes:
title page, heading, cursor on the last-used or `claude` row, the hint line.

```
                              Select agent

                                  1.  agoragentic-acp · Agoragentic
                                  2.  auggie · Auggie CLI
                                  3.  autohand · Autohand Code
                                  4.  bob · Bob
                              ❯   5.  claude · Claude Agent
                                  6.  cline · Cline
                                  …
                              ↑↓ or j/k to move · Enter or 1–9 to select · Esc to cancel
```

At 80×24 the same list, cut by the picker's own height rule.

### `chord agents`

The `riff … built in … --riff-agent` line goes; the first line is the first
catalog agent. The columns keep their widths from what is left.

### The status line

No riff sign-in notices (`src/ui/status/credentials.ts` goes). With any
agent the status line reads as it does today for a non-riff agent.

### No sign-in box

The window's riff sign-in box (ChatGPT / Grok, browser and device code) is
gone; nothing in the window asks for a plan sign-in. An agent's own sign-in
(CHD-435's sign-in block) is unchanged.

### The `/` command list

`/login` and `/logout` are gone from the list and from typed commands. Typed
anyway, `/login` is handled as any other slash command chord does not own,
with nothing riff-specific.

### The shortcuts panel (`?`)

The row `/login /logout  to sign riff in or out` goes. The rows around it
keep their order; the panel is one row shorter.

### An agent named riff

`chord riff`, `agents.riff` in settings, `agent: "riff"` as the default and
a riff record in `/resume` or `chord -r` get chord's usual unknown-agent
handling, with no riff-specific notice (the owner's rule). On the command
line that is the existing line:

```
  error: Unknown agent "riff". `chord agents` lists them.
```

## Colour roles and keys

No colour role is added or dropped from `src/ui/theme/theme.ts` by this
change beyond any used only by riff's sign-in box. No key is added; the
panel loses only the `/login /logout` row, which had no binding of its own.

## Why

The owner dropped riff (CHD-621). A removal that left a trace on screen — a
gap in the picker numbers, an empty status slot, a panel row with nothing
behind it, a special notice for `riff` — would keep riff present in all but
function. The screen should read as if riff had never been there.
