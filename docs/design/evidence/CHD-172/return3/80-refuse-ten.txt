
Usage:   chord [agent]
Version: 0.0.0

Description:

  A full-screen terminal client for ACP coding agents.

Options:

  -h, --help                                 - Show this
                                               help.
  -V, --version                              - Show the
                                               version number
                                               for this
                                               program.
  -C, --cwd                       <dir>      - Directory the   (Default:
                                               session works   "/tmp/chord-qa.X
                                               in.             XXX/proj")      
                                                                               
                                                                               
                                                                              
  --agent-command                 <command>  - Start this ACP
                                               agent command
                                               instead of the
                                               registry's;
                                               [agent] only
                                               names it.
  -m, --model                     <model>    - Start each of   (Conflicts:
                                               [agent]'s       --print)
                                               sessions on
                                               this model, by
                                               its id for it.
  --permission-mode               <mode>     - Start each of
                                               [agent]'s
                                               sessions in
                                               this mode, by
                                               its id for it.
  -c, --continue                             - Open the        (Conflicts:
                                               agent's latest  --resume)
                                               session in
                                               this directory
                                               again.
  -r, --resume                    <id>       - Open a session
                                               by the id
                                               chord prints
                                               on quit;
                                               repeated, a
                                               tab each.
  -p, --print                     <prompt>   - Send this       (Conflicts:
                                               prompt, print   --continue,
                                               the reply and   --resume)
                                               exit; piped
                                               input joins
                                               it.
  --dangerously-skip-permissions             - Allow every
                                               permission the
                                               agent asks
                                               for. Only with
                                               -p.
  --output-format                 <format>   - How -p prints:  (Depends:
                                               the reply as    --print, Values:
                                               it streams, or  "text", "json")
                                               one JSON
                                               object at the
                                               end.

Commands:

  agents  - List the agents chord can start: name, title and command.

Examples:

  Claude Code                  chord claude
  Pick up where you left off   chord claude --continue
  Codex in another directory   chord codex -C ~/src/app
  One question, for a script   chord -p "What does this do?"
  Piped input with the prompt  git diff | chord -p "Review this" --output-format
                               json
  An agent chord does not know chord my-agent --agent-command "my-agent --acp"

  error: A window opens at most 9 sessions; --resume named 10.

exit 2
