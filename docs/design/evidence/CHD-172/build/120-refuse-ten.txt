
  -h, --help                                 - Show this help.
  -V, --version                              - Show the version number for this program.
  -C, --cwd                       <dir>      - Directory the session works in.                (Default:
                                                                                              "/private/tmp/chord-qa.L1
                                                                                              1u/proj")
  --agent-command                 <command>  - Start this ACP agent command instead of the
                                               registry's; [agent] only names it.
  -m, --model                     <model>    - Start each of [agent]'s sessions on this       (Conflicts: --print)
                                               model, by its id for it.
  --permission-mode               <mode>     - Start each of [agent]'s sessions in this
                                               mode, by its id for it.
  -c, --continue                             - Open the agent's latest session in this        (Conflicts: --resume)
                                               directory again.
  -r, --resume                    <ids...>   - Open the sessions with these ids again, a tab
                                               each; chord prints them on quit.
  -p, --print                     <prompt>   - Send this prompt, print the reply and exit;    (Conflicts: --continue,
                                               piped input joins it.                          --resume)
  --dangerously-skip-permissions             - Allow every permission the agent asks for.
                                               Only with -p.
  --output-format                 <format>   - How -p prints: the reply as it streams, or     (Depends: --print,
                                               one JSON object at the end.                    Values: "text", "json")

Commands:

  agents  - List the agents chord can start: name, title and command.

Examples:

  Claude Code                  chord claude
  Pick up where you left off   chord claude --continue
  Codex in another directory   chord codex -C ~/src/app
  One question, for a script   chord -p "What does this do?"
  Piped input with the prompt  git diff | chord -p "Review this" --output-format json
  An agent chord does not know chord my-agent --agent-command "my-agent --acp"

  error: A window opens at most 9 sessions; --resume named 10.

exit=2
